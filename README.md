## Ejecutar un ejemplo

Utiliza **Python 3.10 o superior**; la sintaxis `match` requiere Python 3.10. Desde la raíz del repositorio:

```bash
python ExplicacionesClase/for.py
python Practica1-Introduccion-al-uso-de-python/practica1.py
```

Si tu sistema utiliza el comando `python3`, sustituye `python` por `python3`. Varios ejemplos solicitan valores por la terminal.

Los scripts actuales utilizan la biblioteca estándar de Python. El archivo `dependencias.txt` de la práctica recoge un entorno de desarrollo más amplio; no necesitas instalarlo para ejecutar estos ejemplos.
