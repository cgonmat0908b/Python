## Run an example

Use **Python 3.10 or later**; the `match` syntax requires Python 3.10. From the repository root:

```bash
python ExplicacionesClase/for.py
python Practica1-Introduccion-al-uso-de-python/practica1.py
```

On systems where the command is `python3`, replace `python` with `python3`. Several examples ask for values through the terminal.

The current scripts use Python's standard library. The assignment's `dependencias.txt` captures a broader development environment; installing it is not necessary to run these examples.
